Device tree for OPPO R9 Plus
===========================================

It was announced on March, 2016.

| Memory                  | 4 GB                                                    |
| Shipped Android Version | 5.1.1                                                   |
| Storage                 | 64 GB, 128 GB                                           |
| MicroSD                 | Up to 256 GB                                            |
| Battery                 | 4120mAh mAh (non-removable)                             |
| Dimensions              | 163.1 x 80.8 x 7.4 mm                                   |
| Display                 | 1080 x 1920 pixels, 6.0" AMOLED                         |

| Front Camera            | 16 MP, LED flash                                        |
| Release Date            | March 2016                                              |
